# 🛒 QuickPick POS System

A Java-based Point of Sale application designed to manage supermarket sales, products, inventory, customers, and daily operations.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)
![Maven](https://img.shields.io/badge/Maven-C71A36?style=flat&logo=apachemaven&logoColor=white)
![SQL Server](https://img.shields.io/badge/Microsoft_SQL_Server-CC2927?style=flat&logo=microsoftsqlserver&logoColor=white)
![NetBeans](https://img.shields.io/badge/NetBeans-1B6AC6?style=flat&logo=apachenetbeanside&logoColor=white)

</div>

## ✨ Features

- Sales processing and payment handling.
- Product and inventory management.
- Customer, employee, and supplier management.
- Stock monitoring.
- Invoice generation and printing.
- Sales reports.
- Discount management.
- Built-in calculator.

## 🛠️ Technologies Used

- Java 22
- Apache Maven
- Microsoft SQL Server
- Microsoft SQL Server JDBC Driver
- JasperReports
- Apache NetBeans

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sapuCodes/POS-System-for-SuperMarket.git
   ```

2. Open the project in Apache NetBeans or another Java IDE.
3. Configure the Microsoft SQL Server database connection.
4. Restore the provided `posDatabase(msSQL).bak` database backup.
5. Build and run the project using Maven.
